# Проводник (агент-психолог): как подключить настоящего агента

Сейчас на сайте работает **встроенный проводник** (`src/agent/local.ts`): спокойный сценарный собеседник, работает офлайн, ничего никуда не отправляет. Это заглушка с готовым интерфейсом. Когда будет ваш агент/бот, его подключают **без изменения интерфейса**.

## Где он в интерфейсе
- Кнопка с облачком в шапке (везде) и кнопка «Поговорить / Talk it through» в каждой стадии и в эпилоге.
- Чат — нижняя шторка на телефоне, карточка на десктопе (`src/ui/agent.ts`). Переписка живёт только в памяти страницы; при смене языка сбрасывается.
- Проводник знает, на какой стадии человек: после выбора настроения («Спокойно / Напряжённо / Устал(а) / Любопытно / Тяжело») задаёт вопрос именно этой стадии, потом по одному мягкому вопросу, предлагает сохранить мысль в заметки.

## Контракт (`src/agent/types.ts`)
```ts
interface AgentProvider {
  id: string;
  greet?(ctx): AgentReply | Promise<AgentReply>;               // первое сообщение
  send(messages, ctx, signal?): Promise<AgentReply>;           // ответ на реплику
}
type AgentReply = { text: string; chips?: string[]; offerSave?: boolean };
type AgentContext = { lang, stage /*0..8*/, stageTitle, stageQuestion, mood?, turn };
```
**В контекст не попадают заметки и дневник человека**, только язык, стадия, её вопрос, выбранное настроение и номер реплики.

## Три способа подключить
1. **Свой сервер (рекомендуется).** При сборке задайте `VITE_AGENT_URL=https://ваш-сервер/agent`. Сайт делает `POST` с `{ messages, context }` и ждёт `{ reply, chips?, offerSave? }` (допускаются также `text` / `message`). Ключи API **держите на сервере**, не в браузере.
2. **Во время работы страницы:** `window.OpusAgent.register({ id: 'my-bot', async send(messages, ctx) { return { text: '…' } } })`.
3. **В коде:** заменить провайдер в `src/agent/index.ts`.

## Что обязательно сделать при подключении реального психолога-бота
- Системный промпт: не ставить диагнозы, не давать медицинских/лечебных инструкций, не заменять специалиста; при признаках кризиса мягко направлять к живому человеку и специалисту. Сейчас встроенный проводник на слова об самоповреждении отвечает бережным сообщением без номеров телефонов (по вашему решению — без кризисных телефонов).
- Согласие и приватность: перед отправкой переписки на сервер показать человеку понятное согласие (что отправляется, где хранится). Сейчас этого окна нет, потому что всё локально.
- Юридически и этически: проверка психологом/юристом, возрастные ограничения, хранение данных.
- Тексты интерфейса проводника — `src/i18n/agent.ts` (7 языков; их тоже стоит вычитать носителем).
